# ClassSnag Logo Design Guide

## Logo Concept

The ClassSnag logo should represent speed, precision, and fitness. The visual identity combines the ideas of "snagging" (catching/grabbing quickly) with fitness/gym activities.

## Design Direction

### Primary Concept: "The Snag"
A modern, minimalist icon that suggests quick action and fitness:

**Option 1: Lightning + Dumbbell**
- A stylized lightning bolt integrated with a dumbbell or fitness equipment
- Represents speed and instant booking
- Clean, geometric design

**Option 2: Target Crosshair**
- Circular target with crosshairs (suggesting precision and "snagging" the class)
- Fitness equipment silhouette in the center
- Implies accuracy and getting what you want

**Option 3: Hand Catching**
- Minimalist icon of a hand "snagging" or catching something
- Could be combined with a subtle fitness element (kettlebell, etc.)
- Suggests the "snag" action directly

## Color Palette

**Primary Colors** (matching the extension UI):
- Purple: `#667eea` (primary brand color)
- Violet: `#764ba2` (secondary, for gradients)
- White: `#ffffff` (for contrast)

**Accent Colors** (optional):
- Light gray: `#f7fafc` (backgrounds)
- Dark gray: `#1a202c` (text/outlines)

## Icon Specifications

The logo needs to be created in three sizes for Chrome extensions:

### icon-16.png (16x16 pixels)
- Toolbar icon (very small)
- Should be simple and recognizable at tiny size
- Prefer solid colors over gradients
- Strong silhouette

### icon-48.png (48x48 pixels)
- Extension management page
- Medium detail level
- Can include subtle gradients

### icon-128.png (128x128 pixels)
- Chrome Web Store listing
- Full detail version
- Can include gradients, shadows, and refined details

## Design Guidelines

1. **Simplicity**: Must be recognizable at 16x16 pixels
2. **Distinctiveness**: Should stand out among other extension icons
3. **Relevance**: Should suggest fitness/gym and speed/automation
4. **Modern**: Clean, contemporary aesthetic matching the UI
5. **Scalability**: Design should work from 16px to 128px

## Style Preferences

- **Flat/Semi-flat design** with optional subtle depth
- **Rounded corners** (matches the UI design)
- **Bold, clear shapes** that read well at small sizes
- **Gradient optional** but only on larger sizes (48px+)
- **Professional** but friendly and approachable

## Inspiration Keywords

- Lightning fast
- Precision targeting
- Snag/catch
- Fitness/workout
- Automation
- Speed
- Modern
- Clean

## Technical Requirements

- **File format**: PNG with transparency
- **Color mode**: RGBA
- **Background**: Transparent
- **Padding**: Include ~10% padding from edge for visual breathing room
- **Pixel perfect**: Align to pixel grid, no sub-pixel rendering

## Recommended Approach

1. Start with **icon-128.png** (design at high resolution)
2. Create the detailed version with full colors and effects
3. Simplify for **icon-48.png** (reduce detail, maintain recognition)
4. Further simplify for **icon-16.png** (consider monochrome or two-tone)
5. Test all three sizes in Chrome to ensure visibility

## Tools Suggestions

- **Figma** - Vector design, easy export at multiple sizes
- **Adobe Illustrator** - Professional vector design
- **Inkscape** - Free vector design tool
- **Canva** - Quick prototyping with templates
- **DALL-E / Midjourney** - AI generation for inspiration
