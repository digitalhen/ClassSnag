# ClassSnag identity

The 1.1.0 mark pairs a rounded C with a checkmark: watch for an opening, then confirm the reservation. Purple keeps continuity with the existing interface. The mark has no lettering, fine detail or gym affiliation marks.

- Master: `assets/logo-source.png` (transparent PNG).
- Extension exports: `assets/icon-16.png`, `icon-32.png`, `icon-48.png`, `icon-128.png`.
- Store artwork: `store/assets/promo-440x280.png` and `store/assets/screenshot-1280x800.png`.
- Store artwork is rendered from the actual popup by `npm run test:browser`.
- Icon sizes were exported with macOS `sips` from the generated master.

## Generation provenance

Generated with the built-in image-generation tool, October 7, 2026. Final prompt:

> Use case: logo-brand. Create a polished new app icon for ClassSnag, a browser extension that watches fitness class availability and books an opening. Existing brand palette is purple #667eea and violet #764ba2 with white. Design one bold, simple geometric symbol combining a rounded open C shape with a decisive checkmark that catches the opening, communicating a confirmed booking. White symbol on a rich purple rounded-square tile. Strong silhouette readable at 16 pixels, very few shapes, flat vector-like finish, carefully balanced optical proportions. Single centered icon with about 10% transparent margin outside the tile. No text, letters as typography, gradients, mockups, shadows, badges, fitness equipment, or extra decorations. Output one square icon on a transparent background, production quality.
